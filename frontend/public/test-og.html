🧪 How to Test

  1. Copy this URL: https://dobby.now/test-og.html
  2. Share to WeChat: Paste the URL in a WeChat chat - should show rich preview
  3. Share to Twitter: Tweet the URL - should show large image card
  4. Share to Facebook: Post the URL - should show rich preview
  5. Use debugging tools: Facebook Sharing Debugger, Twitter Card Validator

✅ Expected Results

When shared to social media, this page should display:

  • ✓ Title: "Test Open Graph Meta Tags - Dobby"
  • ✓ Description: "This is a test page to verify Open Graph meta tags..."
  • ✓ Image: Dobby logo (SVG format)
  • ✓ Site Name: "Dobby"

🔧 Troubleshooting

If the preview doesn't work:

  • Cache Issues: Social platforms cache URLs - wait or use debugging tools
  • Image Format: Some platforms prefer JPG/PNG over SVG
  • URL Accessibility: Ensure the URL is publicly accessible
  • Meta Tag Syntax: Verify all meta tags are properly formatted
